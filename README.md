## Featured build

### [Windows Server and Active Directory Support Lab](https://github.com/Mox404/IT-Portfolio/tree/main/active-directory-helpdesk-lab)

Built a Windows Server 2022 domain with a Windows 11 client and used it to practice support, administration, access control, and break fix troubleshooting.

`AD DS` `DNS` `DHCP` `Group Policy` `NTFS` `SMB` `PowerShell` `RDP` `Printer Support`

| Lab area | What I worked on |
| --- | --- |
| Identity | users, groups, OUs, domain logon, account lockout |
| Networking | DHCP, DNS, TCP/IP checks, name resolution |
| Access | SMB shares, NTFS permissions, department isolation |
| Policy | Group Policy drive mapping |
| Support | printer spooler, RDP, client validation |
| Evidence | screenshots and PowerShell checks for each stage |
